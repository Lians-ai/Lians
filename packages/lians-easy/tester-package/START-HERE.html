Test Lians with Claude Pro

This package compares full research history with the smaller set of decisions Lians selects. It gives you a clear token result in one local page.

Run the test

  1. Make sure Claude Code is installed on this Windows computer.
  2. Open Claude Code and sign in to the Claude Pro or Max account you want to test.
  3. If needed, run claude auth login and finish the sign in.
  4. Close any terminal that has ANTHROPIC_API_KEY set. The test refuses API key billing.
  5. Double click LiansResearchTest.exe.
  6. Select Run the research test, then download the report when it finishes.

What the test does

It runs four isolated Claude calls using synthetic research notes. Two use full history and two use Lians context. It checks the same six decisions in every answer and reports provider input tokens. It does not read your files, ask for your password, or store your Claude account details.

These calls use the separate Claude Agent SDK allowance attached to an eligible subscription. They do not prove that every workflow will save the same amount or that an interactive plan limit is extended.

Windows may ask if you trust it

This is an unsigned technical preview. Run it only if this ZIP came directly from Lians and the SHA256 value in SHA256.txt matches the app. The app does not need administrator access. Send the downloaded report to the Lians person who invited you to test it.
