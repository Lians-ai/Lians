Start using Lians

Connect a signed-in AI tool, add a local work export, and run your next task with a smaller context brief.

Open the app

  1. Install and sign in to Claude, Codex, or Cursor using the commands below.
  2. Close terminals that have provider API keys set. Lians refuses API key billing.
  3. Double click LiansPreview.exe. No installation or administrator access is needed.
  4. Choose your AI, add a JSON or JSONL export, and select Create smaller context.
  5. Write the next task and run it. Download the brief and receipt if you want to inspect them.

Sign in once

Claude

Run claude auth login and use a Claude Pro or Max subscription.

Codex

Run codex login and choose ChatGPT sign-in.

Cursor

Run cursor-agent login and finish browser sign-in.

What stays local

Your original export is parsed in the local app and is not uploaded to Lians. Only your task and the bounded brief are sent through the AI tool you select. The brief exists only while the app is open unless you download it.

Windows may ask if you trust it

This is an unsigned technical preview. Run it only if the ZIP came directly from Lians and the SHA256 value in SHA256.txt matches the app.
