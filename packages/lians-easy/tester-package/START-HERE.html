Test Lians with your AI account

Choose Claude, Codex, or Cursor. The local test compares full research history with the smaller set of decisions Lians selects.

Run the test

  1. Install and sign in to at least one supported CLI using the commands below.
  2. Close terminals that have provider API keys set. The test refuses API key billing.
  3. Double click LiansContextTest.exe.
  4. Choose Claude, Codex, or Cursor, then select Run the research test.
  5. Download the report when the test finishes.

Claude

Run claude auth login and use a Claude Pro or Max subscription.

Codex

Run codex login and choose ChatGPT sign-in. API-key login is refused.

Cursor

Run cursor-agent login and finish browser sign-in.

What the test does

It runs four isolated calls using synthetic research notes. Two use full history and two use Lians context. It checks the same six decisions in every answer and reports the input usage returned by the selected CLI. It does not read your projects, ask for your password, or store account details.

Codex runs with user config and rules ignored in a read-only sandbox. Cursor runs in read-only ask mode inside a fresh temporary workspace.

Windows may ask if you trust it

This is an unsigned technical preview. Run it only if this ZIP came directly from Lians and the SHA256 value in SHA256.txt matches the app. The app does not need administrator access.
