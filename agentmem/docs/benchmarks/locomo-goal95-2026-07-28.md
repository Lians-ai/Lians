# Leakage-free LoCoMo 95+ retrieval gate

## Result

The canonical Lians semantic retrieval export and website context pipeline
achieved a 97.53% evidence-hit rate on all 1,536 answerable LoCoMo questions.
The compiled contexts retained 100% of retrieved evidence and no context
exceeded the configured 1,200-token estimate.

This is a judge-free evidence retrieval and context-compilation measurement.
It is not an end-to-end answer-accuracy score.

| Gate | Result |
| --- | ---: |
| Overall evidence hit | 1,498 / 1,536 (97.53%) |
| Compiled evidence hit | 1,498 / 1,536 (97.53%) |
| Retrieved-hit retention | 100.00% |
| Mean compiled context | 1,084.26 estimated tokens |
| Packs over 1,200 tokens | 0 |
| Multi-hop evidence hit | 96.45% |
| Temporal evidence hit | 97.82% |
| Open-domain evidence hit | 89.13% |
| Single-hop evidence hit | 98.69% |

## Frozen protocol

- Semantic top-200 retrieval from the canonical Lians engine.
- One semantic query by default; query expansion is opt-in.
- Reranking weights: `base=1`, `lexical=0`, `neighbor=0.1`.
- The main retrieved turn plus up to two adjacent turns on either side.
- Top-50 fair-share context compilation under a 1,200-token estimate.
- Gold evidence IDs and answers are introduced only after retrieval for
  scoring. They do not enter retrieval, reranking, bundling, or compilation.
- LoCoMo category 5 is excluded because it is adversarial/unanswerable.

## Reproduction

Candidate exports are created from this repository with:

```powershell
python -m benchmarks.locomo_eval `
  --conv 0 `
  --k 200 `
  --embeddings sentence-transformers `
  --db results/goal95/conv_0.sqlite `
  --out results/goal95/conv_0_context_bundles_r2.json `
  --dump-candidates `
  --include-context
```

`benchmarks/run_goal95_exports.ps1` automates conversations 2–9. Each exported
conversation is then scored with the website repository's
`benchmarks/semantic-rerank.js`. The ten frozen reports are aggregated and
strictly verified from the website repository:

```powershell
$reports = Get-ChildItem results -Filter 'semantic-rerank-*-r2.json' |
  Sort-Object Name |
  ForEach-Object { $_.FullName }
node benchmarks\verify-goal95.js --reports @reports --out results\goal95-final.json
```

The machine-readable final result is `results/goal95-final.json` in the website
repository.
