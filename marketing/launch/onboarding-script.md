# Fifteen-minute activation session

## Before the call

- Ask the participant to choose Claude Code, Codex, or Cursor.
- Ask them to use a disposable project or synthetic decision.
- Do not request credentials, memory text, project files, or screen recordings.
- Record only consented funnel outcomes in the cohort scorecard.

## Session

### Minute 0–2: expectation

Ask: “What do you think Lians will do after looking at the GitHub page for ten
seconds?” Record their words before explaining anything.

### Minute 2–6: connect

Let the participant follow the repository quickstart without coaching. Note the
first hesitation. Help only after they describe what they expected.

### Minute 6–9: save

Use this synthetic decision:

> Remember that this test project uses PostgreSQL, not SQLite.

Confirm locally that the client is connected and the memory exists.

### Minute 9–12: fresh session

Open a new task or supported AI tool and ask:

> Which database should this feature use?

Activation succeeds only when the current project decision is reused. A GitHub
star, package download, successful install, or empty context request does not
count.

### Minute 12–14: correction

Change the synthetic decision, then verify that the old decision is marked stale
and is not returned as current.

### Minute 14–15: five questions

1. What did you expect Lians to do?
2. Where did setup become uncertain?
3. Did the fresh-session answer feel trustworthy?
4. Would you be disappointed if Lians disappeared tomorrow?
5. Would cross-device continuity or shared team memory be worth paying for?

Ask separately before using their name, company, quote, or screen in marketing.
