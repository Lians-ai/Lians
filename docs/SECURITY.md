# Security policy

The canonical Lians security policy is the repository-level
[SECURITY.md](../SECURITY.md). It contains the supported-version policy, private
GitHub vulnerability-reporting route, scope, response process, and researcher
safe-harbor guidance.

Do not report a vulnerability through a public issue. This repository does not
publish a verified security email address.

For implementation assumptions and residual risk, see the [production threat
model](threat-model.md).
