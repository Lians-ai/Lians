# Join the Lians developer community

The easiest contribution is to install Lians in a real AI workflow and report
where the memory loop becomes confusing, slow, or unreliable.

## Start with one memory

1. Install [Lians Easy](easy-install.md) or use the [MCP setup](install.md).
2. Save a fact in one chat.
3. Recall it in a later chat or a second supported client.
4. Correct it, inspect the history, and test confirmed forgetting.
5. Share what worked or the smallest reproduction of what did not.

## Where to participate

- Ask implementation questions in GitHub Discussions Q&A.
- Share a working agent, test result, or failure in Show and tell.
- Propose product and integration ideas in Ideas.
- Open an issue for a reproducible bug or client request.
- Follow [SECURITY.md](SECURITY.md) for private vulnerability reports.

## Community principles

- Real workflows and reproducible evidence beat promotional claims.
- Honest failure reports are contributions.
- Never post credentials, personal data, or confidential records.
- No purchased stars, reciprocal-star campaigns, or manufactured engagement.

See the [product roadmap](../ROADMAP.md) and [contribution guide](CONTRIBUTING.md).
